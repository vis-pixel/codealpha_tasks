📘 Student Grade Tracker (Java)
A simple, interactive, and user-friendly Student Grade Tracking System built in Java.
This project demonstrates OOP, Collections, Serialization, and File Handling.

🚀 Features
✨ Core Functionalities
1.➕ Add Student

2.📝 Add Marks (supports multiple marks at once)

3.📄 View Individual Student Report

4.📊 View All Students Summary

5.💾 Auto Save & Load Data using Serialization



📈 Report Details Include:
1.List of all marks
2.Average score
3.Highest score
4.Lowest score


🛠️ Technologies Used
1.Java (JDK 8+)
2.Object-Oriented Programming
3.ArrayList Collection
4.File I/O with Serialization
5.Scanner for Input  


📂 Project Structure
StudentGradeTracker/
│
├── StudentGradeTracker.java   # Main program
|-- StudentGradeTracker.class  
|-- Student.class 
└── students.dat   # Auto-generated data storage file            

▶️ How to Run the Program
1️⃣ Compile
    ->javac StudentGradeTracker.java
2️⃣ Run
    ->java StudentGradeTracker
