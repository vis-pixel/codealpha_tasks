🤖 AI Chatbot – Java Swing Application

This project is a simple AI Chatbot built using Java Swing as part of the CodeAlpha Internship (Task – AI Chatbot).
The chatbot provides automated responses using keyword-based intent processing and a predefined FAQ database, all within a user-friendly graphical interface.


📌 Features
🖥️ Graphical User Interface (GUI) using Java Swing
💬 Real-time chat interaction
🧠 Intent-based response processing
📚 FAQ-based answers related to CodeAlpha internship

⏰ Supports general queries like:
1.Greetings
2.Current time
3.Weather (simulated)
4.Jokes

Internship-related questions
🎨 Styled chat messages with different colors for user and bot
🚪 exit command to safely close the chatbot


🛠️ Technologies Used
1.Java
2.Java Swing
3.AWT
4.Collections Framework
5.StyledDocument (for colored text)


🧩 Project Structure
FAQDatabase
Stores predefined questions and answers
Uses HashMap for fast lookup
IntentProcessor
Processes user input
Matches keywords and returns appropriate responses
AIChatbot
Main GUI class
Handles user interaction and message display


▶️ How to Run the Project
Make sure Java JDK is installed on your system
1.Save the file as:
   AIChatbot.java
2.Compile the program:
   javac AIChatbot.java
3.Run the program:
   java AIChatbot
